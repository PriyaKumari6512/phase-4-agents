# Clarifications: Repeat no-show block and no-show report

No user was available, so each question has an assumed answer. They go to the client in the next clarification round.

## Q1: Undoing a no-show that caused a block

- **Context**: FR-022 lets reception undo a no-show the same day. FR-025 does not say what happens to a block that this no-show created.
- **Options**:
  - A. The block is removed when the person is back under 2 no-shows; no lift record is made.
  - B. The block stays until reception lifts it.
  - C. The undo is refused once it would unblock a patient.
- **Assumed**: A.
- **Why**: A no-show marked by mistake should not leave a patient blocked, and the "2 no-shows in 6 months" rule in FR-025 is the test. Reception's lift action is meant for deliberate decisions.

## Q2: What "after the lift" means for counting

- **Context**: FR-026 says lifting starts the count again from zero. A no-show for an earlier appointment could be marked after the lift.
- **Options**:
  - A. A no-show counts if it was marked after the lift time.
  - B. A no-show counts if the appointment's start time is after the lift time.
- **Assumed**: A.
- **Why**: Reception can only mark a no-show from 15 minutes after the start until end of day, so the two usually agree. Marked time is simple to check and matches the audit record kept for every status change.

## Q3: The unfinished current month in the report

- **Context**: FR-032 says "each of the last 12 months" and defines the rate as no-shows divided by appointments not cancelled. The current month includes future booked appointments, which would lower the rate.
- **Options**:
  - A. Show 12 months ending with the current month, labelled "month so far", using the PRD formula as written.
  - B. Show the 12 completed months only.
  - C. Show the current month but count only appointments whose start time has passed.
- **Assumed**: A.
- **Why**: It follows FR-032 as written and gives the manager early figures from the first month after release. The label tells them it is incomplete. The client can choose B or C.
