## Gaps for a human

- bootstrap: create the remote state bucket 'clinic-test-2-tfstate' (versioned, encrypted) once per account
- taskflow-web is public: set ingress.host and ingress.certificateArn in gitops/apps/taskflow-web/<env>/values.yaml; the AWS Load Balancer Controller and DNS come from the platform bootstrap
- notify-worker runs the taskflow-api image: set its start command in gitops/apps/notify-worker/<env>/values.yaml (args)
- bootstrap: register Argo CD clusters named clinic-test-2-dev, clinic-test-2-stg, clinic-test-2-prod; install platform CRDs before syncing platform applications
- shared container registries are owned only by dev/core state; apply that state before image builds for other environments
- platform add-ons (external-secrets operator, kube-prometheus-stack, OpenTelemetry Collector) are installed by the platform team's cluster bootstrap; their chart versions are not pinned here
- module terraform-aws-modules/eks/aws ~> 21.0 is a version range, not a verified pin; confirm it with infra_registry_versions
- module terraform-aws-modules/ecr/aws ~> 2.0 is a version range, not a verified pin; confirm it with infra_registry_versions
- module terraform-aws-modules/rds/aws ~> 6.0 is a version range, not a verified pin; confirm it with infra_registry_versions
- module terraform-aws-modules/elasticache/aws ~> 1.0 is a version range, not a verified pin; confirm it with infra_registry_versions
- image promotion is not generated: CI builds and pushes images, and a new tag reaches gitops/apps/<component>/<env>/values.yaml through a PR to the infra repo (or Argo CD Image Updater, installed by the platform team)
